CARGO CLASH
COMP4122 course project. A truck has crashed. Collectors carry the scattered cargo back to the
truck, and Interrupters smash it. A level has two 1-minute halves, and the sides swap at half-time.

RUNNING THE GAME
1. Unzip the whole folder first. The game won't run from inside the zip.
2. Double-click CargoClash.exe.
   If Windows says it protected your PC, click More info, then Run anyway. The program isn't code-signed.
3. To play alone, click PLAY, then PRACTICE WITH BOTS, then the TUTORIAL card. No network or account
   is needed. The other levels are locked for now.

CONTROLS
WASD                 Move
Mouse                Look around (the arrow keys turn too)
E                    Pick up / put down cargo
Space or right-click Ram
Hold left-click or F Smash cargo (Interrupters only)
V                    Switch between first person and over the shoulder
Esc                  Pause menu, where you can change the look speed
Alt+Enter            Full screen on / off
A gamepad also works: left stick to move, right stick to look, A / B / X to pick up, ram and smash.

PLAYING TOGETHER ON A LOCAL NETWORK
One player clicks CREATE ROOM and chooses a level. The room code is that computer's IP address.
The others type the code and click JOIN.
If Windows Firewall asks on the host's computer, click Allow access.

REQUIREMENTS
64-bit Windows 10 or 11 with a graphics card that supports Direct3D 11.
