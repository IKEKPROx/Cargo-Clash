# 玛雅遗迹（MAYA RUINS）关卡与机制说明

这是 Cargo Clash 第 5 张地图「玛雅遗迹」的说明，给接手的同学看。前半部分讲玩法和机制，后半部分讲随附的 Blender 包和工程里对应的文件。

---

## 1. 一句话概括

一辆运货卡车撞进了丛林里的玛雅遗迹，货物散落在遗迹各处。**拾取方**要把货搬回卡车得分，**破坏方**要阻止他们、砸毁货物。场地中间横着一道残破城墙，墙上的三道可破坏的门是两队必争的近路。

- 每半场 **2 分钟**，打两个半场，中场两队交换攻守。
- 可以走的范围：x 10～115 米，南边到公路护栏，北边到 z 66.4 米（约 105 × 73 米）。

---

## 2. 场地布局

坐标约定：x 向东，z 向北，y 向上，单位米（Blender 包里是 x 东、y 北、z 上）。

| 区域 | 位置 | 说明 |
|---|---|---|
| 卡车（交货点） | 约 (63, 6.5)，车头朝北 | 卡车停在场地南边，车斗周围是交货区；车头左前角压在塌掉的残墙上 |
| 拾取方出生点 | 卡车附近，南边 | 3 个出生位 |
| 破坏方出生点 | 场地北端，约 (60～68, 61～62) | 3 个出生位 |
| 中部城墙 | 沿 z≈22，从 x=30 到 x=93.5 | 高 2.2 米，挡住南北，只有三道门能过（见第 4 节）。两头（x<30、x>93.5）一直通 |
| 中央高台 | 约 x 55～73，z 36～46 | 高 2.5 米，北面有宽台阶，台上有 30 分货 |
| 两座货仓 | 西仓约 (44.5, 36.5)，东仓约 (82, 37.5) | 各放一件 100 分大箱，仓门敞开；侧墙 R9、R10 可破坏 |
| 两个深坑 | 西坑 x 24～33 × z 34～45；东坑 x 89.75～97 × z 28～40 | 深 3.5 米，坑边有黄色警示牌（有碰撞） |

## 3. 货物

共 **43 件，总分 1040**。每个货点放哪种货是固定的，开局刷出，中场重置。

| 分值 | 货物 | 数量 | 砸毁时间 | 说明 |
|---|---|---|---|---|
| 10 | 烟盒 / 现金箱（交替） | 23 | 2～3 秒 | 一个人就能搬 |
| 30 | 金条箱 | 17 | 7 秒 | 一个人就能搬，多数放在高台和塔顶上 |
| 100 | 鹅木箱 | 3 | 16 秒 | **要两个人合抬**。两座货仓各一件，大金字塔顶上一件 |

- 南半区（卡车一侧）货少分低，北半区和高处货多分高。破坏方出生在北边，离高分货更近。
- 搬到卡车车斗的交货区放下就得分。
- 货掉进深坑后可以从坑底台阶搬上来；跌落到 −6 米以下会自动回到出生位置。

## 4. 中部城墙与可破坏墙（核心机制）

### 4.1 哪些墙能破坏

一共 **5 堵**：

- 城墙上的三道门：**R3**（x≈46）、**R5**（x≈64.8，正对卡车）、**R4**（x≈82），相隔约 18 米。
- 两座货仓的侧墙：**R9**、**R10**。

每堵墙都是一块块石头垒起来的。

### 4.2 破坏

| 谁 | 怎么做 | 效果 |
|---|---|---|
| 破坏方 | 锤子砸一下 | 整堵墙倒下 |
| 拾取方 | 吹风机（左键）吹 **3 下** | 第 1 下吹飞最上面一层的大部分石块，第 2 下再飞掉一批，第 3 下整堵墙塌掉 |

- 吹过的缺口会一直保留，直到墙被修好或被打倒。
- 准星对着墙时有提示：「吹倒墙（还要吹 N 下）」。

### 4.3 修复

- 拾取方对着倒掉或有缺口的墙**按住右键吸 2 秒**，石块会飞回原位。
- 墙倒后要等 **1 秒** 才能开始修。
- 站在缺口里吸也算对着这堵墙。墙合上时，缺口里的人和货会被挪到各自那一侧。

### 4.4 石块

- 被吹飞或砸飞的石块是实心的，落在墙的另一侧，也就是背对动手的人那一边。
- 落地的石块有 0.24 米高的碰撞：人能踩上去，货会被挡住。
- 每台电脑上石块落的位置都一样。

### 4.5 战术意义

- 三道门都完好时，破坏方要绕城墙两头才能到卡车，拾取方也要绕两头才能进中部的货仓和高台。
- 任何一道门打开，两边都能直穿。实测：
  - 破坏方从出生点到卡车：96 米 → 72 米
  - 拾取方从出生点到西货仓：45 米 → 32 米
- 所以破坏方开门是为了快速冲到卡车边干扰交货，但同时也替拾取方开了近路。拾取方可以自己吹开门去抢货，也可以修门挡住破坏方。

## 5. 其他机制

- **阶梯神殿和金字塔**：坡道约 30°，角色能直接走上去。每层台面和塔顶都能站人。
- **深坑分叉台阶**：从坑南沿正中下一段台阶，到坑内 −1 米、横贯全坑的平台，再沿东西两面坑壁各有一段台阶下到坑底。掉下去从哪一侧都能上来。台阶边有斜边栏和黄色防滑条。
- **中央高台**：北面台阶可以直接走上去。另有托举（两人配合把队友托上去）和藤梯两种上法。
  - 藤梯需要藤蔓，但场上的藤蔓道具已经删掉，所以目前玩家用不上；规则代码还保留着。
- **卡车撞墙**：卡车车头左前角的轮子已经掉了（落在墙另一侧），车轴压在塌掉的残墙碎块上。
- **小地图**：显示收小后的场地范围、城墙、可破坏墙、坑和台阶。

## 6. 主要数值（`GameConfig`）

| 字段 | 值 | 含义 |
|---|---|---|
| `ruinBlastsToBreak` | 3 | 拾取方吹几下吹倒一堵墙（1～3） |
| `ruinRestoreSeconds` | 2 | 吸多久修好一堵墙 |
| `ruinWallSwitchCooldown` | 1 | 墙倒下或修好后多久才能再动它 |
| `ruinPitReturnHeight` | −6 | 低于这个高度自动回到坑的回位点 |
| `ruinBoostSeconds` | 2.5 | 托举用时 |
| `ruinLadderSeconds` / `ruinClimbSeconds` | 16 / 1.6 | 藤梯持续时间 / 爬一次用时（目前用不上） |
| 半场时长（`LevelLayout.halfSeconds`） | 120 | 每半场秒数 |

## 7. 随附的 Blender 包

文件是 `MayaRuins.blend`，用 Blender 4.x / 5.x 打开。贴图已经打包在文件里，单独拷走也能用。

### 7.1 里面有什么

- **Level 集合**：游戏里实际显示的整张地图，约 323 万面，454 个物体，包括：
  - 原有的遗迹环境
  - 新加的金字塔、神殿、宫殿、城墙
  - 一块块石头垒成的可破坏墙
  - 坑和台阶、残墙碎块
  - 公路、护栏、警戒带、警示牌
  - 树林和远山
  - 地上的路面痕迹

  这是从运行中的游戏里直接导出的，所以和游戏里看到的一致：已经清掉的碎石草团、隐藏掉的旧墙都不在里面，游戏运行时才生成的公路和石墙都在里面。
- **Layout markers 集合**：关卡设置，都是空物体，在物体属性的「自定义属性」里能看到数据。
  - `Spawns`：两队各 3 个出生点，箭头方向就是出生朝向，属性 `team`。
  - `Cargo spots`：43 个货点，方块大小区分分值，属性 `value`（10 / 30 / 100）和 `cargo`（货物种类）。
  - `Truck delivery zone`：交货区范围。
  - `Pits`：两个坑的范围和回位点。
  - `Boost and ladder`：托举和藤梯的起点、终点。
  - `Breakable walls`：5 堵可破坏墙的范围，属性 `wall`、`height`。
  - `Play area`：可活动范围的框。
- 一盏太阳光、天空颜色、一台对着大金字塔的相机。

**没有包含**：人物、卡车、直升机、货物模型。这些不属于地图，由各自的模型文件负责。

### 7.2 坐标和导出

- Blender 里 x 向东、y 向北、z 向上，单位米，和游戏的位置一一对应：游戏 (x, y, z) = Blender (x, z, y)。
- 植物、树皮、玛雅石块的颜色在顶点色里，材质用 `Color Attribute → Gamma(0.4545) → Base Color` 还原游戏里的亮度。
- 公路和地面痕迹用带透明通道的贴图（`RuinRoad.png`、`RuinDecals.png`），石头和原有环境用图集 `RuinAtlas.png`。
- 要导出给别的软件，直接用 Blender 的 `File > Export` 导出 FBX / glTF / OBJ 即可。glTF 会保留顶点色。

### 7.3 怎么重新生成这个包

地图改了以后，按下面的步骤重新导出：

1. 打 Mac 包，然后运行游戏导出关卡：

   ```bash
   "Builds/Mac/CargoClash.app/Contents/MacOS/Cargo Clash" -batchmode -nographics -ccMode practice -ccLevel 4 -ccBotLocal -ccTimeout 300 -ccExportLevel Builds/MayaRuins_Export
   ```

2. 用 Blender 组装：

   ```bash
   /Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python Tools/blender/build_ruin_delivery.py -- Builds/MayaRuins_Export Builds/Delivery/MayaRuins.blend
   ```
