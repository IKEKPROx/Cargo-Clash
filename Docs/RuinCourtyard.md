# 藤坠石庭 V07 接入

接入基线为 Cargo-Clash main 的 `45d5afe`。项目使用 Unity **6000.6.1f1**。打开 `Assets/CargoRover/Scenes/CargoRover.unity` 并进入 Play Mode，从 **PLAY → PRACTICE WITH BOTS → RUIN COURTYARD** 进入。开房使用 **CREATE ROOM → RUIN COURTYARD**。真人房间需要双方人数相同，允许机器人补齐。

新场景 `Assets/Game/Scenes/LevelRuinCourtyard.unity` 复用原 HUD、相机、货车和直升机。它通过 V07 资源生成 124 × 69 米地形、碰撞和机器人导航，每半场按布局放置 8 小、5 中、2 大共 15 箱。所有门和破坏点的状态由 `MatchDirector` 同步。每半场复位墙、门、藤蔓和货物。

| 地图交互 | 操作 |
| --- | --- |
| 两座货仓门 | 空手朝门按 E。门扇扫掠范围内有人或有箱时等待清空。 |
| 12 处可破坏点 | 阻拦方用左键锤击。R7 先裂后断，落下的板件仅作表现。搬运方用右键持续吸回，复原会等开口清空。 |
| 投藤 | 靠近卷藤按 E 拾取。朝地面瞄准并按 E，落点合法时铺开，范围内减速 30%，持续 6 秒。 |
| 东侧藤梯 | 持藤走到高台东侧按 E 挂藤并攀爬，其他人也能在挂藤期间使用。每次允许一人上梯。 |
| 南侧托举 | 两个空手队友到南侧站位分别按 E。第二人上台后可从上端按 E 拉队友。西侧台阶供下行。 |
| 落坑 | 玩家回到同侧的回场点。落坑货物或随玩家落坑的未交货货物复位至原货位，已计分货物不会重生。 |

待实机检查的几项行为

1. 主机与客户端分别开门、击碎墙和复原。将角色、普通箱和合搬箱分别堵在门口与墙洞，确认占位时状态不切换。
2. 检查 R7 上站人时第二次敲击的落脚，以及下一半场是否复原。确认 R9/R10 打开后在两端取箱，通过门洞后能走到交货区。
3. 分别检查高台下方隔墙取货、投藤落在坑沿、藤梯到时有人占用、托举队友离开、两名玩家争抢上端落脚点。
4. 玩家和货物先后落入两坑。确认只复位未交货的箱子，两队比分不变。
5. 打完两半并观看直升机结算，确认队伍交换位置、互动状态和 15 箱重置。机器人会走地面导航并可开门。主动投藤和合作托举目前由玩家操作。
6. 返回教学关，核对原来的箱数缩放、开房和练习。

自动测试可从现有客户端程序传 `-ccMode practice -ccLevel 4 -ccBotLocal -ccQuit` 跑新场景的对局流程。实际交互仍需两人实机检查。当前本地完成了 C# 语法、场景引用、资源 GUID、布局和 LFS 校验。Unity 编译、导航烘焙、Play Mode 与联机没有运行。
